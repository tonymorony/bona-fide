# Fonts

Self-hosted because the page's CSP allows no other origin. Each file is the Google Fonts **latin** subset (U+0000-00FF and common punctuation; no U+2713 check mark), as a **variable** font with a weight axis.

| File                          | Family                          | Weight range |
| ----------------------------- | ------------------------------- | ------------ |
| `big-shoulders-display.woff2` | Big Shoulders Display (display) | 100–900      |
| `hanken-grotesk.woff2`        | Hanken Grotesk (body)           | 100–900      |
| `azeret-mono.woff2`           | Azeret Mono (labels, serials)   | 100–900      |

Source: Google Fonts css2 API (`fonts.gstatic.com`), downloaded 2026-10-06. Licence: SIL Open Font License 1.1. The copyright lines and full text are in `OFL.txt`.
